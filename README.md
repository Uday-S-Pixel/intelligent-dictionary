# Intelligent Dictionary and Auto-Complete System

A C-based mini project implementing a dictionary and auto-complete
system using a Trie data structure.

## Team Members

1. Vasu
2. Likitha
3. Uday
4. Annanya

## Project Overview

This project aims to build an intelligent dictionary that can:

- Search for words
- Insert new words
- Search for prefixes
- Provide auto-complete suggestions
- Rank suggestions based on word frequency
- Update the dictionary dynamically

## Data Structures Used

- Trie
- Strings
- Arrays
